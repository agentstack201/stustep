## ⚠️ اكتشاف يحتاج قرارك — صفحة بيضاء على الويب

**الموقع:** `lib/main.dart` — **ملف محظور، فلم يُعدَّل.**

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(...);   // ← بلا try/catch
  ...
  runApp(...);                          // ← لا يُنفَّذ إن فشل ما قبله
}
```

**المشكلة:** على الويب يُجلب Firebase JS SDK من `gstatic.com` وقت التشغيل.
أي فشل في الوصول إليه (شبكة تحجب النطاق · انقطاع مؤقت · حاجب إعلانات) يجعل
`initializeApp` ترمي، فلا يُستدعى `runApp` إطلاقاً — والنتيجة **صفحة بيضاء
تماماً بلا أي رسالة**، لا شاشة خطأ ولا زر إعادة محاولة.

**تحقُّق فعلي:** حمّلت النسخة المبنية في متصفح Chromium حقيقي على شبكة
تحجب `gstatic.com`. المحرّك يُقلع وCanvasKit يعمل، ثم تتوقف الصفحة بيضاء
عند `Initializing Firebase firebase_core`.

**الحل المقترح — ثلاثة أسطر، ولا يغيّر السلوك عند النجاح:**

```dart
try {
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
} catch (e) {
  debugPrint('Firebase init failed: $e');   // التطبيق يُقلع ويعرض خطأً مفهوماً
}
```

> ⚠️ `main.dart` ملف مشترك يمسّ عمل كل الفريق. **القرار قرارك**: إما أن
> تُطبّقه بنفسك، أو تتفق عليه مع الفريق، أو تتركه وتذكره في المناقشة
> كخطر معروف موثّق. لم أعدّله التزاماً بقاعدة الملفات المحظورة.
